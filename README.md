# Travels

**Тема проєкту:** Облік подорожей (поїздки, місця, витрати; географія й вартість відпочинку).

**Про застосунок:**
Цей вебзастосунок розроблений для мандрівників, які хочуть зручно планувати свої поїздки та зберігати детальну історію мандрівок. Він дозволяє вести облік відвіданих місць, фіксувати всі супутні витрати, а також аналізувати загальну географію та вартість відпочинку. Завдяки застосунку користувачі зможуть легко контролювати свій туристичний бюджет та структурувати дані про кожну подорож.

**Основна сутність: Trip (Поїздка)**
Властивості: Id (ідентифікатор), Destination (Місце), Description (Опис), StartDate (Дата початку), EndDate (Дата завершення), TotalCost (Вартість), IsBusinessTrip (Відрядження), Status (Статус).

**Особливість проєкту:**
Реалізація завантаження та показу зображень для записів (додавання фотографій з подорожей).
